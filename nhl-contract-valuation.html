This project was developed as my master’s thesis in Business Analytics at Elon University. The goal was to estimate NHL player contract value by analyzing historical player performance, contract outcomes, salary cap context, and player-level attributes.

The final output included a predictive modeling workflow and an interactive Tableau dashboard designed to present player-level contract valuation cards. The dashboard allows users to review model-based contract expectations and compare them against actual contract outcomes.

Business Problem

NHL teams must evaluate player contracts under salary cap constraints, where overpaying or undervaluing players can affect roster construction and long-term competitiveness. This project approached contract valuation as a predictive analytics problem: using historical data to estimate a player’s expected contract value based on performance, position, age, team control, and other relevant factors.

Methods and Workflow

  • Cleaned, merged, and structured player performance, contract, and salary cap datasets.
  • Created features related to contract value, salary cap percentage, player age, position, draft status, and on-ice performance.
  • Tested multiple modeling approaches, including regression, regularized regression, random forest, gradient boosting, and XGBoost.
  • Compared model performance using error metrics and selected the strongest-performing model for contract value estimation.
  • Translated model outputs into player-level visuals through an interactive Tableau dashboard.

Final Dashboard

The Tableau dashboard presents individual player cards with contract projections, actual contract outcomes, and key valuation context. The goal was to make the model results easier to understand for both technical and non-technical users.

The dashboard emphasizes practical communication: instead of only showing model metrics, it organizes the outputs around individual players so users can quickly interpret projected value, contract comparisons, and important valuation factors.
